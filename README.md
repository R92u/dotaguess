# Dota Match Guess 2.3

Сайт ежедневно показывает два матча, выбранных из 100 последних уникальных матчей четырёх отслеживаемых игроков.

## Главное исправление 2.3

Матчи теперь гарантированно одинаковы для всех посетителей в течение московского календарного дня:

- пул фиксируется по матчам, начавшимся **до 00:00 МСК** текущего дня;
- два матча выбираются детерминированно по дате и `APP_SECRET`;
- новый матч, сыгранный в течение дня, не меняет текущую пару;
- перезапуск Render и работа нескольких экземпляров сервиса не меняют пару;
- в 00:00 МСК автоматически формируется новая пара.

Версия схемы данных повышена до 5, поэтому после деплоя старая запись текущего дня будет один раз пересоздана уже по фиксированному алгоритму.

## Render

- Build Command: `npm install`
- Start Command: `npm start`

Основные переменные:

```env
NODE_ENV=production
TRUST_PROXY=true
PLAYER_ACCOUNT_IDS=1524768829,1675188627,367813952,390845935
MATCH_POOL_SIZE=100
APP_SECRET=постоянная-длинная-строка
DATABASE_URL=Internal Database URL
ADMIN_SECRET=секрет-для-команды-очистки
```

`APP_SECRET` должен оставаться неизменным: он участвует в детерминированном выборе матчей.

После загрузки файлов выполните **Manual Deploy → Clear build cache & deploy**.
Проверка версии: `/api/health` должна вернуть `2.3.0`.

## Локальный запуск

```bash
npm install
cp .env.example .env
npm start
```

Тесты:

```bash
npm test
```
