# Dota Match Guess

Готовый сайт-игра: раз в сутки выбирается один матч из 20 последних матчей игрока Dota 2 с account ID `1524768829`. Посетитель видит составы, статистику и предметы всех 10 героев, но не видит исход, пока не нажмёт **«Победа»** или **«Поражение»**.

## Что реализовано

- реальные данные через OpenDota;
- один общий матч дня для всех посетителей;
- фиксация матча до 00:00 по Москве, даже если игрок сыграл новые матчи в течение дня;
- исключение вчерашнего матча из выбора, когда есть другие варианты;
- карточки двух команд и боковая панель с предметами по клику на героя;
- результат и ID матча не передаются браузеру до ответа;
- после ответа появляются ссылки на OpenDota и STRATZ;
- адаптивная версия для телефона;
- серверный кэш в JSON: обычно требуется только несколько запросов к OpenDota в сутки;
- Dockerfile и запуск без сторонних npm-зависимостей.

## Быстрый запуск

Требуется Node.js 20 или новее.

```bash
cp .env.example .env
# Задайте длинный случайный APP_SECRET в .env
node --env-file=.env server.js
```

Откройте `http://localhost:3000`.

Для разработки:

```bash
node --env-file=.env --watch server.js
```

Тесты:

```bash
npm test
```

## Docker

```bash
docker build -t dota-match-guess .
docker run -d \
  --name dota-match-guess \
  -p 3000:3000 \
  -e APP_SECRET='replace-with-a-long-random-string' \
  -v "$PWD/data:/app/data" \
  dota-match-guess
```

Для сохранения одного матча на весь день каталог `/app/data` должен быть постоянным volume. Без volume после перезапуска контейнера матч дня может быть выбран заново.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `PORT` | порт HTTP-сервера | `3000` |
| `PLAYER_ACCOUNT_ID` | 32-битный Dota account ID | `1524768829` |
| `OPENDOTA_API_KEY` | необязательный ключ OpenDota | пусто |
| `APP_SECRET` | подпись идентификатора игры | тестовое значение, заменить в production |
| `DATA_DIR` | каталог хранилища матча дня | `./data` |
| `TRUST_PROXY` | учитывать `X-Forwarded-For` за reverse proxy | `false` |

## Развёртывание

Для обычного VPS достаточно запустить Node-процесс через systemd или PM2 и направить Nginx на `127.0.0.1:3000`. При использовании Nginx задайте `TRUST_PROXY=true`. HTTPS лучше завершать на Nginx или Cloudflare.

Для serverless-платформ локальное JSON-хранилище не подходит: потребуется заменить `JsonStore` на Redis, PostgreSQL, KV или другое постоянное хранилище. На VPS и в Docker с volume текущая реализация работает без изменений.

## Источник данных

Приложение использует OpenDota endpoints:

- `/players/{account_id}/recentMatches` — последние 20 матчей;
- `/players/{account_id}` — профиль;
- `/matches/{match_id}` — полный состав, статистика и предметы;
- `/constants/heroes` и `/constants/items` — названия и изображения.

Профиль игрока должен иметь открытые публичные данные матчей. Иногда новый матч появляется в OpenDota с задержкой или содержит неполные данные до обработки матча сервисом.
